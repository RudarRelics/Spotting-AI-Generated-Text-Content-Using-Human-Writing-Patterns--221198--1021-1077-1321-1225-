## Abstract
This project addresses the growing challenge of detecting AI-generated text content. Five machine learning classifiers — Naive Bayes, Decision Tree, Random Forest, SVM, and Logistic Regression — were evaluated on a dataset of ~400,000 samples using TF-IDF (unigrams + bigrams) features. Logistic Regression achieved the best accuracy of 98.88% and was deployed as a Flask web application.

## Results
